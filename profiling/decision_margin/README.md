# 决策裕度、翻转率与后悔值

这个目录回答一个问题：**预测误差要大到什么程度，才会把选出来的策略选错；选错了又亏多少。**

它不测量、不跑模拟器、不改任何成本表。输入是一个已经冻结的 campaign：
`predictions.json` 里记录着每个程序每条动作的坐标键，`profile-frozen.json`
里记录着每个键的价格与原始重复样本，所以"扰动价格再重选"就是对着这些键做一次
求和，不做任何仿真。

## 三个量，不是一个指标

| 量 | 定义 | 回答什么 |
|---|---|---|
| 裕度 `margin` | `(T2 − T1) / T1`，前两名预测值的相对差 | 这次决策离翻盘有多远 |
| 翻转 `flip` | 扰动价格后 `argmin` 是否改变 | 误差到这个量级会不会选错 |
| 后悔 `regret` | `(实测[选中] − min 实测) / min 实测` | 选错了实际亏多少 |

**翻转不等于损失。** 两个候选差 0.3% 时误差 2% 就会让它们换位，后悔值约等于 0。
只报翻转率会把一个稳健的结论说成摇摆不定，所以三个必须一起报。

**解析半径**：若每个价格最多错 `eps`，则排序一定不变的条件是

```text
T1·(1+eps) < T2·(1−eps)   ⟺   eps < (T2−T1)/(T1+T2) = m/(2+m)
```

这是算术，不是实验。实验只是验证这个界在真实误差分布下有多保守。

## 两个必须做对的建模细节

1. **扰价格条目，不扰策略总时长。** 两个策略常常共用价格（同一个 projection 价、
   同一条搬运价），共用部分的误差会互相抵消。在策略总时长上加独立噪声等于
   拆掉这种抵消，翻转率会被系统性高估。本模块只对 `(kind, device, phase, shape)`
   这一级的价格抽样，再让每个策略按自己的合成路径重新求和。

2. **共同模式不会翻转。** 所有价格同乘一个因子时每个总时长同乘该因子，排序不变。
   `common_mode_cannot_flip()` 把这个结论做成可执行的检查，测试里也钉住了。

两种扰动：

- `bootstrap_prices`：每个价格从它自己的实测重复样本里重采样，取均值。这是**下限**，
  只反映采样噪声。
- `scaled_prices`：每个价格独立地乘以 `1+δ`，`δ ~ U(−ε,+ε)`。这是"若每个价格
  最多错 ε"的读数，与实测误差分布同量纲。

## 运行

```text
PYTHONPATH=. python -m profiling.decision_margin.run \
  --campaign <e2a-v2 目录> --output <新目录> [--draws 2000] [--seed 17]
```

输出 `decision-margin.json`：每个决策的裕度、解析半径、基准选择与实测选择、
基准后悔值；`varepsilon` 扫描下每个工作负载的翻转次数与选择分布；bootstrap
翻转与后悔分布；以及 24 个程序的观测预测误差（用来说明扰动范围不是随手定的）。

campaign 目录被搬到 `paper-write/simulator-archive/build/` 之后，证据回执里的
绝对路径仍指向原来的 `Simulator/build/`；`relocated()` 负责把前缀改到归档位置，
找不到就跳过该条样本（不会把缺失当成 0）。

## 结果（E2A，2026-10-25 campaign，笔记本）

预测值的复算残差为 0（价格按 `predictions.json` 的键求和 == 存储的预测值）。

| 工作负载 | 选择 | 次优 | 裕度 | 解析半径 | bootstrap 翻转 |
|---|---|---|---|---|---|
| h256-d1h128 | s0 | s2 | 11.70% | 5.53% | 0/2000 |
| h256-p16 | s0 | s2 | 20.10% | 9.13% | 0/2000 |
| h256-p64 | s2 | s0 | 103.12% | 34.02% | 0/2000 |
| h512-d1h128 | s0 | s2 | 19.90% | 9.05% | 0/2000 |
| h512-p16 | s2 | s0 | 40.86% | 16.96% | 0/2000 |
| h512-p64 | s2 | s1 | 109.06% | 35.29% | 0/2000 |

观测预测误差（24 个程序）：中位 1.58%、P90 4.64%、最大 5.98%。
每价格独立 ±ε 抖动下 6 个决策的合计翻转：ε ≤ 15% 全部为 0，
ε = 20% 时 11/12000，最大后悔 23.82%。

也就是说：**这些决策不是刀锋上的**，最小裕度 11.70% 已经是最大观测误差的近两倍；
解析半径给出的最保守界（5.53%）刚好压在最大观测误差附近，而经验翻转率在 15% 以内是零。

## 边界

- 只对**已经测过**的 campaign 成立；换机器要重跑 campaign，裕度会变——这本身就是
  "价格属于机器、不跨机器搬运"的又一个后果。
- 扰动模型假定价格误差可加、相对、按条目独立；共同模式已证明恒不翻转，
  但**条目间相关**只由"共用价格各自求和"这一层隐式保留，没有从实测里估计。
- 后悔值取自同一 campaign 的 heldout 进程均值；campaign 里没有的候选策略无法估价。
- 测试：`PYTHONPATH=. python -m unittest profiling.tests.test_decision_margin`（19 条，不碰硬件）。
